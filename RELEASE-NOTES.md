# SEO Evidence Lab v0.1.0

First local portfolio release: a reproducible local application and synthetic evidence walkthrough.

## Included

- A responsive Evidence Lab journey through original/edit passages, findings, counterfactual replay, evaluation, news leads, and article review.
- Four pinned replay factors: article, guidance, scoring, and evidence availability. The demonstrated criterion checks headings.
- Five-scope SEO auditing plus a separate Bot-worthiness assessment with revisions, reviewer evidence, history, and exports.
- Saved Firecrawl-shaped capture ingestion, transactional attempt/version history, synthetic competitor observations, and saved Search Console/CrUX imports.
- SQLite FTS5 passage retrieval, three read-only local MCP tools, and local OpenTelemetry spans.
- Six evaluation cases with visible incorrect canned judgments and a documented retrieval miss.
- Pinned setup, synthetic reports, screenshots, an actual recording, and a manually triggered GitHub Actions workflow.

## Verification and identity

The tested application baseline is `ec88b48ae5d0fc74d51bdf1227ad267c52c93fe6`: 264 tests plus 24 subtests passed locally, with fresh-extraction, browser, download, MCP, and restart checks. Subsequent release-preparation edits are documentation only. Remote CI has not run. [Evaluation details](docs/EVALUATION.md).

Hermes Management support supplied independently reproduced community-provenance, measurement-consistency, and evaluation-identity fixes. SEO QA integrated and verified them. Support used Codex local review and offline checks; it did not run a separate paid Hermes model runtime.

## Boundaries

The news agent/service bridge, live Reddit collection, live Ahrefs/GSC/CrUX acceptance, and genuine Jev/Langfuse service acceptance are future milestones. Canned evaluation improvement is not evidence of model improvement. Search-performance observations do not establish causation. Independent editorial votes remain unmeasured despite owner local-MVP signoff.

The existing protected static preview is read-only. Original production remains paused; the dynamic local app is not publicly deployed. No new hosting or provider calls are needed to publish this source release. The owner selected public `j-zulick/seo-evidence-lab`; MIT covers project-owned code under the owner’s final publication approval; dependency licenses remain separate.
