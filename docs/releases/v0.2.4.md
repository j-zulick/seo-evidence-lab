# v0.2.4

Makes faceted evidence search available to agents and scripts: a read-only MCP tool and a local JSON endpoint.

- **Ask from an MCP client:** run `python -m seo_qa.timeline_mcp` and call `search_evidence` with a query and optional sources or versions.
- **Fetch JSON locally:** open `/qa/evidence-search.json?q=noindex&source=fixture:publisher-a` in the local app.
- **Check what a match means:** every response carries provenance hashes and states its coverage limits.

**Assets:** `seo-evidence-lab-v0.2.4-source.zip` is the source release and `SHA256SUMS` lets you check it. Full details: [CHANGELOG](https://github.com/j-zulick/seo-evidence-lab/blob/main/CHANGELOG.md).

## Boundaries
- Lexical matching over the frozen synthetic corpus only; a match does not prove a claim.
- The MCP server is a local stdio tool; it is not hosted.
