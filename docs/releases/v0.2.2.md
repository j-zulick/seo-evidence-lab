# v0.2.2

Adds source and version filters to local evidence retrieval, and modernizes CI.

- **Filter evidence by source and version:** `faceted_search(db, query, sources=[...], versions=[...])` returns matching passages with counts for each facet and stable paging.
- **Browse the whole corpus:** an empty query lists every indexed passage with the same facet counts.
- **Check provenance:** every result keeps its source, version and passage hashes.

**Assets:** `seo-evidence-lab-v0.2.2-source.zip` is the source release and `SHA256SUMS` lets you check it. Full details: [CHANGELOG](https://github.com/j-zulick/seo-evidence-lab/blob/main/CHANGELOG.md).

## Boundaries
- A lexical match is not evidence that a claim is true; counts cover indexed passages only.
- Facets are a Python API; there is no UI or hosted integration yet.
