# v0.2.3

Brings source and version filters to the local evidence-search page, and pins the CI runner.

- **Filter in the browser:** open `/qa/evidence-search`, search, then tick a source or version to narrow the passages.
- **Browse without a query:** tick a filter with the search box empty to list every passage from that source.
- **Read counts honestly:** each filter shows how many indexed passages match, with provenance hashes on every result.

**Assets:** `seo-evidence-lab-v0.2.3-source.zip` is the source release and `SHA256SUMS` lets you check it. Full details: [CHANGELOG](https://github.com/j-zulick/seo-evidence-lab/blob/main/CHANGELOG.md).

## Boundaries
- Lexical matching only, over the frozen synthetic corpus; a match does not prove a claim.
